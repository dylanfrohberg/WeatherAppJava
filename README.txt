# Current Weather App 🌦️

A JavaFX application to retrieve and display current weather data based on a provided ZIP code. This project integrates two APIs to provide weather information and convert ZIP codes into geographical coordinates. It's perfect for a quick weather check with a visually appealing interface.

---

## Features
- 🌡️ Displays the current temperature in Fahrenheit.
- 💨 Shows wind speed and direction with compass labels (e.g., North, South).
- 🌤️ Displays the weather condition (e.g., Clear Sky, Rainy).
- 🕒 Indicates whether it is day or night based on the location.
- 📍 Provides location details (City, State) based on the ZIP code.
- 🎨 Dynamic background images based on weather conditions (e.g., sunny, rainy, snowy).
- 📖 Includes an About Overlay explaining the project.

---

## Prerequisites
Before running the application, make sure you have:
1. Java Development Kit (JDK) 8+ installed.
2. JavaFX libraries included in your project (if not bundled with your JDK).
3. Internet access to fetch data from the APIs.
